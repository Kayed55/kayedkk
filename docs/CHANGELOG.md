## [2026-08-25] — قسم عزوة + إصلاحات Creative Gene + تصحيح تاريخ الرفع (v=111 → v=116)

### ✨ New Features
- **تصحيح تاريخ رفع تقييم Creative Gene** (Feature 1، `v=116`): موظفة الجودة/المدير يصحّحون `week_start` لطلب رفع خاطئ عبر زر «✏️ تعديل التاريخ» في «طلبات التقييم». مسموح فقط قبل إنشاء التقييم (`pending_quality` + `evaluation_id IS NULL`)، والتاريخ يُطبَّع تلقائياً لسبت الأسبوع. RPC جديد `qo_update_upload_date` (`security-migration/72`, PR#74) — SECURITY DEFINER + Anon-Only + حارس تعارض + تدقيق (`wf_audit action='date_correction'` + `audit_logs`).

### 🐛 Bug Fixes
- **عزل قسم عزوة في «الأخطاء المتكررة»** (`v=111`): كانت الصفحة تخلط معرّف القسم الرقمي بفلتر الاسم النصّي فتُظهر بيانات محزم؛ فُصل الفلتر (`deptName`) وحُفظ عزل القسم عبر تغيير الفلاتر.
- **«تقرير الإجراءات» لعزوة كان يعرض أرقام محزم** (`v=112`): بطاقات الإحصاء ورسم الإجراءات كانت تقرأ كل التقييمات؛ حُصرت بقسم الصفحة.
- **قائمة القسم في التقارير لا تُظهر عزوة** (`v=112`/`v=113`): تُبنى الآن من `departments (is_visible_in_ui)` بدل أقسام الموظفين، مع حارس تحميل قبل الرسم في «تقرير الجودة» و«الأخطاء المتكررة».
- **رابط «موظفوني — Creative Gene» اليتيم** (`v=114`): استُعيد في قائمة مشرف CG (كان بلا مدخل UI منذ تنظيف PR#71/#72) — يظهر لمشرف CG فقط.
- **لبس نافذة اتخاذ إجراء المشرف** (`v=115`): كانت تملأ حقول المشرف باقتراح الجودة وتعطّلها؛ صارت حقول المشرف تبدأ فارغة دائماً واقتراح الجودة بطاقة مرجعية للقراءة فقط.
- **طلبات CG لا تختفي بعد التقييم** (M71، PR#73): سبب جذري — `create_evaluation_request` يحفظ `week_start` غير مُطبَّع فيتعارض مع `ON CONFLICT`؛ أُصلح بـtrigger تطبيع + تنظيف الصفوف العالقة.

### 🏗️ Data / Migrations
- `security-migration/71` — تطبيع `week_start` لأسبوع CG على السبت (trigger) + دمج/إغلاق الصفوف المكرّرة والعالقة.
- `security-migration/72` — `qo_update_upload_date` (Feature 1 أعلاه).

## [1.0.0] - 2026-06-22 — ✅ الإصدار المعتمد للإطلاق (Production)

### 🔒 الأمان — الإغلاق الكامل (المرحلة 2-ب)
- **سحب INSERT/UPDATE/DELETE/TRUNCATE نهائياً عن `anon`** على كل الجداول (تبقى SELECT للقراءة فقط) — `security-migration/20`.
- **كل الكتابات عبر RPCs بـ `SECURITY DEFINER` مُصادَقة بجلسة** (token 64-hex، صلاحية 7 أيام) مع تحقّق دور على الخادم؛ الهوية والتدقيق واحتساب الدرجات تُحسم على الخادم — العميل غير موثوق.
- تعطيل الرفع المباشر `pushAll` (الكتابة عبر RPCs فقط) — `writeViaRpcOnly`.
- إلزام الرمز في العمليات الحسّاسة (حذف التقييم/إعادة تعيين كلمة المرور) — لا مسارات انتقالية.
- إضافة `.gitignore`؛ لا تسريب لأي مفتاح في التاريخ.

### 👤 الصلاحيات
- **موظف الجودة (`quality_officer`):** تعديل قالب التقييم (إضافة/تعديل/حذف أقسام/فرعية/بنود + الأوزان) وإضافة/تعديل التقييمات.
- محصور على الأدمن: حذف التقييمات، إدارة المستخدمين، إعادة تعيين كلمات المرور.

### 🐞 إصلاحات حاسمة
- **الكاش:** HTML `no-store` + آلية تحديث تلقائي للتبويبات المفتوحة (بلا Cmd+Shift+R).
- **المزامنة:** سحب مُجبَر بعد الكتابة + حارس تسلسل يمنع سحباً قديماً من الكتابة فوق بيانات أحدث (حلّ "لا يظهر إلا بعد تحديث").
- **تعديل القالب:** إصلاح المرجع المتقادم في مودالات التعديل + تعبئة مفاتيح الأقسام الفرعية (كانت بلا `key` فلا تُعدَّل).

### ✨ ميزات وإصلاحات هذه الدورة
- **التصنيف الثنائي**: ≤84 راسب / ≥85 ناجح في كل النظام (واجهة + تقارير + PDF/Excel).
- **توحيد بريد EmailJS** على قالب واحد `template_universal` (9 دوال إرسال) + إصلاح تعارض كسر الخدمة.
- **قائمة جانبية متجاوبة** (درج + هامبرغر + Overlay + Escape + قفل تمرير) على ≤768px.
- **حذف تقييم متزامن وذرّي** (RPC cascade + tombstones) — يختفي من كل الأقسام ولا يعود.
- **تحديث تلقائي عند التنقّل** بين الأقسام (جلب طازج + مؤشّر تحميل + حارس تعديلات + إعادة محاولة).
- إصلاح `42804`/`42702` في دوال إعادة التعيين وOTP.

### 🧹 جاهزية الإنتاج
- إزالة كل بلوكات `[EmailJS DEBUG]` التشخيصية.
- عنوان تبويب المتصفّح يتغيّر حسب القسم؛ تتبّع أخطاء عميل خفيف → `audit_logs`.
- وثائق جديدة: `USER_GUIDE.md`, `BACKUP.md`, `ADMIN_RECOVERY.md`.
- فهارس قاعدة البيانات مكتملة على الأعمدة الأكثر استخداماً.
